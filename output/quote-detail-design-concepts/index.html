1. Quote Desk Recommended

Best for daily editing. Focused task tabs, a persistent financial summary, visible distance/date notices, and a clear Save / Preview / Send action shelf.

Mobile: one task section at a time; summary drawer and labelled sticky actions. Tradeoff: additional tab navigation; one shared draft must survive tab changes and errors.

2. Event Dossier

Best for reviewing the complete event. A single-page event file combines customer/event facts, itemized pricing, agreement/deposit tracking and internal notes, with section anchors instead of tabs.

Mobile: anchored sections in a deliberate reading order with collapsible long sections. Tradeoff: more vertical scrolling; edit controls and save scope must stay explicit.

3. Pricing Studio

Best for preparing multiple quote options. An itemized comparison table dominates the workspace, with a preparation sidebar for totals, warnings, notes and customer communications.

Mobile: select an option to inspect/edit; compare options through a dedicated comparison view. Tradeoff: strongest for pricing, less direct for routine customer/event edits. Recommended does not mean customer selected.
