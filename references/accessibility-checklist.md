# Accessibility Checklist

- [ ] WCAG 2.2 AA target documented
- [ ] Landmarks and skip link
- [ ] Logical heading structure
- [ ] Full keyboard operation and visible focus
- [ ] Focus not obscured by sticky UI
- [ ] Correct accessible names, roles, states, and values
- [ ] Text and UI contrast pass
- [ ] 200% text resize and 400% zoom/reflow
- [ ] No color-only meaning
- [ ] Touch targets and spacing are usable
- [ ] Persistent form labels and associated errors
- [ ] Dialog and menu focus management
- [ ] Purpose-based alt text
- [ ] Captions/transcripts where required
- [ ] Reduced-motion behavior
- [ ] No autoplay or flashing barrier
- [ ] Error prevention for consequential submissions
- [ ] Screen-reader smoke test on core journeys
